# Bloom Plan — Decision-Transparent Planning

Activate: `/bloom-plan`, `/plan`, "plan this". Deactivate: `/plan-off`. Artifacts → `.cursor/plans/`.

**The Loop:** Research (read-only) → Plan (`.plan.md` + `.plan.html`) → Approve (pause) → Execute → Verify

**Scale:** Greenfield (full tables), Brownfield (impl tables only), Phase ("which approach" tables)

**Decision Tables (mandatory, 3-4 alternatives):** Example=concrete, Benchmark=verifiable, Why not chosen=specific. HTML: expandable cards, `--clay` chosen.

**Plan structure:** Header → Context → Prerequisites → Decisions → Steps → Risks → Verification

**HTML Companion:** Bloom Rules 1-12 + S1-S8. Decision cards, localStorage checklist, risk matrix, status timeline, scale badge, copy-as-markdown, print.
