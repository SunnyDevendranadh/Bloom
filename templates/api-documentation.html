Users API v2

Base URL https://api.northwind.example/v2 · Updated May 15, 2026

Authentication

All requests require Authorization: Bearer <token> from the Northwind identity service. Scopes: users:read, users:write.

GET /users/{id}

Returns a single user record. Supports include=teams for expanded membership.

FieldTypeDescription
idstringULID identifier
emailstringPrimary login email
statusenumactive, suspended, invited

Errors

404 when the user is unknown; 429 when rate limit exceeded (see Retry-After header).
