ADR-018: Edge cache for read-heavy routes

Status Accepted · May 10, 2026

Context

Catalog and pricing endpoints serve 12k RPS at peak with 94% cacheable responses. Origin CPU is saturated despite horizontal scaling.

Decision

Deploy a regional edge cache with 60s default TTL and cache-key normalization on Accept-Language + currency only.

Consequences

  • Positive: Expected 40% origin offload; p95 drops ~120ms.
  • Negative: Stale price risk — mitigated with purge webhooks on write.
  • Neutral: Ops owns runbooks; no app code changes for v1 paths.
