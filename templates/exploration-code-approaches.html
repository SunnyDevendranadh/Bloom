Code exploration — Auth middleware

Prompt Compare three ways to validate JWTs at the edge without adding more than 2ms p95 latency.

01Local JWKS cache

Fetch signing keys once per region; verify in-process.

const key = await cache.get(kid);
return jwt.verify(token, key, { algorithms: ['RS256'] });
Pro
Con
Lowest latency after warm cache
Key rotation edge cases
No external call per request
Memory per region
Bundle: +4 KB Testability: High

02Introspection sidecar

Delegate validation to a colocated gRPC sidecar.

const ok = await sidecar.Introspect({ token });
if (!ok.active) throw new Unauthorized();
Pro
Con
Centralized policy updates
Extra hop ~1.2ms
Bundle: 0 KB app Testability: Medium

Recommendation

Start with local JWKS cache for read paths; keep introspection sidecar for admin scopes only.
